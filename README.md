# VES School Locator

An interactive **Institution Directory and School Locator** for the **Vivekananda Educational Society (VES)**.

This project provides a modern, mobile-friendly interface that allows parents, students, teachers, and visitors to quickly locate VES institutions using an interactive map.

---

## 🌟 Features

- 🏫 Interactive School Directory
- 🗺️ OpenStreetMap Integration
- 📍 Marker Clustering
- 🔍 Instant School Search
- 📱 Mobile Responsive Design
- 📞 Click-to-Call Support
- 🌐 School Website Links
- 🧭 One Click Directions
- 📧 Email Support
- ⚡ Fast Loading using JSON Database

---

## 🚀 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Leaflet.js
- OpenStreetMap
- Leaflet MarkerCluster
